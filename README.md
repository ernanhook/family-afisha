# Афиша для малыша 👶

Еженедельная сводка семейных мероприятий по Латвии в Telegram: погода, события на выходные и неделю, бесплатное, ближайшие праздники и идеи постоянных мест. Работает на GitHub Actions, ИИ — Claude Haiku (около $0.10–0.15 в месяц, лимит $0.90).

## Файлы
| Файл | Что в нём | Менять? |
|---|---|---|
| `settings.txt` | возраст, регион, день и час сводки, погода, бюджет | да |
| `criteria.txt` | что подходит и что нет, обычным языком | да |
| `categories.txt` | категории событий и их значки | да |
| `sources.txt` | сайты с афишами и запросы в Google News | да |
| `places.txt` | постоянные места для блока «Куда ещё сходить» | да |
| `holidays.txt` | праздники для блока «Скоро» | да |
| `main.py` | сам скрипт | не нужно |
| `.github/workflows/digest.yml` | расписание запуска | не нужно |
| `state.json` | память бота, создаётся сам | нет |

## Быстрый старт
1. Telegram: @BotFather → `/newbot` → токен; напишите боту `/start`; chat_id — в `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
2. Claude: platform.claude.com → пополнить баланс → API Keys → Create Key.
3. GitHub: новый публичный репозиторий → загрузить все файлы → Settings → Secrets and variables → Actions → секреты `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Actions → Family events digest → Run workflow — сводка придёт сразу.

Подробная пошаговая инструкция и примеры доработок — в документе «Афиша для малыша: инструкция».
# Афиша для малыша 👶

Еженедельная сводка семейных мероприятий по всей Латвии в Telegram. Каждое событие приходит отдельной карточкой с кнопками «🗺 Карта» и «📅 В календарь». На карточку можно поставить 👍 или 👎, и бот запомнит, что вам нравится.

Бот работает на GitHub Actions, ИИ — Claude Haiku. Обычный месяц стоит около $0.30–0.45, лимит задаётся в `settings.txt`.

## Что приходит в Telegram
- **Четверг 10:00 — сводка на две недели.** Сначала обложка «что внутри». Дальше разделы по дням: «Сегодня и завтра», «Выходные» с погодой, «Будни», «В любой день». В конце: бесплатные события одним списком, свёрнутый список «Ещё для детей и семей», блоки «Скоро» и «Куда ещё сходить», ⭐ Совет недели.
- **Пятница 18:00 — напоминание на выходные:** короткий список событий из сводки и свежая погода.
- **⚡ Срочные анонсы:** если на новостных порталах объявили что-то крупное (цирк, большой семейный фестиваль), бот пришлёт карточку сразу. Не больше 2 в неделю.

## Файлы
| Файл | Что в нём | Менять? |
|---|---|---|
| `settings.txt` | возраст (или месяц рождения), регион, дни и часы рассылок, бюджет | да |
| `criteria.txt` | что подходит и что нет, обычным языком | да |
| `sources.txt` | сайты с афишами, порталы и запросы в Google News | да |
| `distances.txt` | сколько ехать из Риги до городов (строка «🚗» на карточке) | можно |
| `categories.txt` | категории событий и их значки | да |
| `places.txt` | постоянные места для блока «Куда ещё сходить» | да |
| `holidays.txt` | праздники для блока «Скоро» | да |
| `recurring.txt` | регулярные события, которые вы знаете | да |
| `main.py` | сам скрипт | не нужно |
| `.github/workflows/digest.yml` | расписание запуска (каждый час) | не нужно |
| `state.json` | память бота: оценки, история, очередь новостей; создаётся сам | нет |

## Оценки 👍 / 👎
- Сделайте бота **администратором группы**: тогда он видит реакции на карточках.
- Без прав администратора можно **ответить на карточку** словом «👍», «да», «хочу» или «👎», «мимо», «нет». Бот поставит на ваш ответ 👌, когда учтёт его (в течение часа).

## Быстрый старт
1. Telegram: @BotFather → `/newbot` → токен. Добавьте бота в группу; chat_id группы видно в `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
2. Claude: platform.claude.com → пополнить баланс → API Keys → Create Key.
3. GitHub: публичный репозиторий → загрузить все файлы → Settings → Secrets and variables → Actions → секреты `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (и при желании `OPENWEBNINJA_API_KEY`).
4. Actions → Family events digest → Run workflow — сводка придёт сразу.

Подробная пошаговая инструкция — в документе «Афиша для малыша: инструкция».
